HIDDEN INDIA — VIRASAT OF BHARAT EDITION

To open the preview on your computer, open index.html in a web browser.

To make a public link for friends and use location on phones, host these four files on a secure (HTTPS) static website:
  index.html
  manifest.json
  icon.svg
  sw.js

One free option is GitHub Pages:
1. Create or sign in to a GitHub account.
2. Create a new public repository named hidden-india. (With GitHub Free, Pages requires a public repository, so the app files will be publicly viewable.)
3. Upload the four files above to the repository's main folder.
4. Open Settings, then Pages. Choose “Deploy from a branch”, select “main” and “/(root)”, then save.
5. GitHub will show the public website address in Settings > Pages. It usually looks like:
   https://YOUR-GITHUB-NAME.github.io/hidden-india/

The hosted app asks permission before using location. The user can also search for a town. Nearby results include mapped Hindu places of worship and heritage landmarks; coverage depends on local map data. Location search and story loading need an internet connection. Photo previews stay on the device. If a JPEG photo contains GPS metadata, the app reads it locally and can search nearby; it does not recognise a landmark from the image itself. Shared photos often have GPS removed. Commons photos are loaded for place cards with an author/attribution link when a suitable result is available.

The heritage-inspired interface now opens through a Kashi ghats doorway photograph. It draws on wada thresholds, Rajputana jharokhas, carved timber, sandstone and brass. The first Sanātana collection includes Kedarnath, Kashi, Rameswaram, Hampi, Puri, Kamakhya, Ujjain, Somnath, Mathura–Vrindavan, Ayodhya and Tirumala. The fort section features Chittorgarh Fort and the Patan–Satara Bhairavgad documented by the Maharashtra Gazetteer. It is an initial offering, not a complete catalogue. Each place links to a reference; story cards also offer video and podcast search links for further exploration. Sacred narratives are clearly presented as tradition and belief.
