HIDDEN INDIA — VIRASAT OF BHARAT EDITION

To open the preview on your computer, open index.html in a web browser.

To make a public link for friends and use location on phones, host these four files on a secure (HTTPS) static website:
  index.html
  manifest.json
  icon.svg
  sw.js

One free option is GitHub Pages:
1. Create or sign in to a GitHub account.
2. Create a new public repository named hidden-india. (With GitHub Free, Pages requires a public repository, so the app files will be publicly viewable.)
3. Upload the four files above to the repository's main folder.
4. Open Settings, then Pages. Choose “Deploy from a branch”, select “main” and “/(root)”, then save.
5. GitHub will show the public website address in Settings > Pages. It usually looks like:
   https://YOUR-GITHUB-NAME.github.io/hidden-india/

The hosted app asks permission before using location. The user can also search for a town. Nearby results include mapped Hindu places of worship and heritage landmarks; coverage depends on local map data. Location search and story loading need an internet connection. Photo previews stay on the device. This version does not identify a place from image pixels alone; use the nearby search or sacred places collection to find a matching landmark.

The heritage-inspired interface draws on wada thresholds, Rajputana jharokhas, carved timber, sandstone and brass. The first Sanātana collection includes Kedarnath, Kashi, Rameswaram, Hampi, Puri, Kamakhya, Ujjain, Somnath, Mathura–Vrindavan, Ayodhya and Tirumala. It is an initial offering, not a complete catalogue. Each place links to a cultural or tourism reference; sacred narratives are clearly presented as tradition and belief.
